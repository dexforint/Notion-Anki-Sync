# Notion Anki Sync

https://github.com/dexforint/Notion-Anki-Sync/raw/refs/heads/main/assets/demo.mp4

[English](README.md) · **Русский**

Расширение Chrome: **toggle** в Notion → карточка Anki из меню блока (шесть точек).

- **Front** = название страницы + заголовок toggle
- **Back** = содержимое toggle в HTML «как в Notion» (текст, списки, цитаты, callout, код с подсветкой, LaTeX, таблицы, вложенные toggle, картинки)
- Колода выбирается при синхронизации
- **Unsync** удаляет заметку в Anki
- Если Anki закрыт, изменения ставятся в очередь
- **Sync all now** / фоновая проверка:
  - обновляет изменённые toggle
  - удаляет карточку, если блок исчез из Notion
  - снимает бейдж, если заметку удалили в Anki
- На втором компьютере те же карточки и бейджи через **AnkiWeb** (источник правды — Anki)
- Картинки не качаются повторно, если файл уже есть в медиа Anki

AnkiWeb и телефон получают карточки обычной синхронизацией Anki. Публичного API записи в AnkiWeb нет.

## Установка

1. [Anki](https://apps.ankiweb.net/) и [AnkiConnect](https://foosoft.net/projects/anki-connect/) (код `2055492159`). Anki лучше держать запущенным.
2. Notion → **Settings → Connections → Develop or manage integrations** → **Internal Integration** → скопируйте токен.
3. На каждой нужной странице: **••• → Connections** → добавьте интеграцию.
4. Chrome → `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** → папка проекта.
5. **Настройки** расширения: вставьте токен, **Test Notion** / **Test Anki**, сохраните.

## Использование

1. Наведите на **toggle** → шесть точек.
2. Панель Anki: колода → **Sync**.
3. Бейдж справа на блоке — toggle отслеживается.
4. Снова откройте панель: **Update** или **Unsync**.
5. Попап на панели браузера → **Sync all now**: полный проход, сводка и список карточек.

Новую колоду можно ввести в поле. Удалённые колоды пропадают из списка, пока Anki запущен.

## Два компьютера

Карточки живут в Anki. Синхронизируйте их через **AnkiWeb**.

Расширение при старте и по **Sync all now** читает все заметки типа `Notion Toggle` и восстанавливает бейджи. Локальную базу копировать не нужно.

На втором ПК:

1. Anki + AnkiConnect, синк с AnkiWeb.
2. То же расширение и тот же токен Notion (или синхронизация профиля Chrome — токен и колода по умолчанию едут в `chrome.storage.sync`).
3. Notion → **Sync all now**.

Очередь «Anki был закрыт» существует только на том компьютере, где её создали.

## Приватность

Токен Notion хранится в Chrome. Запросы только на `api.notion.com` и локальный AnkiConnect (`127.0.0.1:8765`). Своего сервера нет.

## Ограничения

- Notion в Chrome. Пункт меню — оверлей (DOM Notion нельзя менять).
- Только блоки **toggle**.
- Запись в Anki — только Desktop + AnkiConnect.
- Пока Anki закрыт, удаление заметки в Anki расширение не увидит.
